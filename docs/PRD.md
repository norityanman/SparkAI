## 1. 背景

中小企業の多くは人手不足に悩んでいる。DX の広告の多くは「ツールで人を減らす」「コスト削減」を打ち出すが、ITに詳しい人がいない会社ほど「うちには無理」と感じて動けない。

ReFast の SparkAI は、DX 支援・システム構築・AI 人材教育を**伴走型**で提供し、「今いる人を伸ばす」ことで人手不足を解決する。この違いを、短い動画で伝えたい。

## 2. 目的

1. 「DX＝人を減らす」ではなく「DX＝人を伸ばす」という SparkAI の考え方を知ってもらう
2. 「ITが苦手でも大丈夫」と感じてもらい、**無料相談（30分）** の申し込みにつなげる
3. 同じ会社・同じ世界観の連続ドラマにして、シリーズとして追いかけてもらう

## 3. 対象者

| 対象 | 状況 | 刺さってほしい一言 |
|---|---|---|
| 中小企業の社長（主対象） | 求人を出しても人が来ない。DX は気になるが社内に詳しい人がいない | 「人が足りないなら、人を伸ばせばいい。」 |
| 現場の社員 | パソコンや AI が苦手、仕事を取られるのが不安 | 「AIに仕事を取られると思ってた。逆だった」 |
| 若手社員 | 雑務を一人で抱えて疲れている | 「怒られる前に、“すごい”って言われた。」 |
| 独立・副業を考える個人（横型シリーズ） | 売れるスキルがない | 「通勤電車の30分で、AIを学ぶ」 |

## 4. メッセージ

- **メインコピー：** 人が足りないなら、人を伸ばせばいい。
- **サブコピー：** ITは、人を減らすためじゃない。人が輝くためにある。
- **行動の呼びかけ（CTA）：** 無料相談 30分／プロフィールのリンクから
- **物語の型：** 悩み → SNS で知る → 相談 → 学ぶ → 成功体験 → 明るい未来
- 最後は「システムが入った」ではなく「人生・仕事が変わった」で終わる

## 6. 要件

### 6-1. 映像

| # | 要件 |
|---|---|
| V1 | 縦型は 1080×1920・30fps、横型は 1920×1080 |
| V2 | 長さは 15〜60秒。冒頭 3 秒で主人公の本音のテロップを出し、スクロールを止める |
| V3 | 最後に 4.5〜5 秒のエンドカード（キャッチコピー・SparkAI・無料相談・株式会社ReFast）を入れる |
| V4 | 登場人物の見た目は、台本の設定表どおりに全シーンでそろえる |
| V5 | 不自然なコマ（手のない物が浮く、など）は切り取る |

### 6-2. テロップ

| # | 要件 |
|---|---|
| T1 | 音を消して見ても話がわかる（SNS は無音再生が多いため） |
| T2 | 1 枚 2 行まで、1 枚あたり 2.5 秒以上表示する |
| T3 | 縦型は Zen Kaku Gothic New、横型は Noto Sans CJK JP で統一する |
| T4 | 実績の数値には「※イメージです」を添える。実データが手に入ったら差し替える |

### 6-3. 音

| # | 要件 |
|---|---|
| A1 | BGM・効果音はスクリプトで合成したオリジナルのみを使う（著作権フリーを保証） |
| A2 | 生成映像に入っている人の声は消す（Demucs）。ナレーションは入れない |
| A3 | 曲の盛り上がりを、物語の転換点（「3か月後」、成功の場面）に合わせる |

### 6-4. 再現性

| # | 要件 |
|---|---|
| R1 | 完成動画はすべて、リポジトリ内のスクリプトと外部素材から作り直せる |
| R2 | テロップの文言と秒数は、スクリプトか `.ass` ファイルを直すだけで変えられる |
| R3 | 作り方は `README.md` に、コピーしてそのまま使えるコマンドで書く |

## 7. 完成の条件

1本の動画は、次をすべて満たしたら「完成」とする。

- [ ] 6章の要件（V・T・A）をすべて満たしている
- [ ] 音を消した状態で通して見て、話が伝わる
- [ ] スマートフォンの実機で見て、テロップが読める大きさ・位置になっている（UI に隠れない）
- [ ] 数値の表記・誤字脱字・会社名・サービス名を確認した
- [ ] `README.md` の手順で作り直せることを確認した
- [ ] `README.md` の動画一覧に載せた

## 8. 成功の指標（配信後に測る）

| 指標 | 見る理由 |
|---|---|
| 3秒視聴率 | 冒頭のフックが効いているか |
| 完全視聴率 | 物語が最後まで見てもらえるか |
| 保存数・シェア数 | 「教わる人が、教える人になった」などの一文が刺さっているか |
| プロフィールへの移動率・無料相談の申込数 | 最終目的に結びついているか |

目標値は、初回の配信結果を見てから決める。
