# 子育てブランク編「恵、38歳。娘の作文に、私の仕事が書かれた日。」

> 流れ：悩み → SNSで知る → クリック → 相談 → 学ぶ → 成功体験 → 輝かしい未来
> サービス名：SparkAI ／ 会社名：株式会社ReFast

## なぜ「広く多くの人」に届くのか
これまでの話は、工場・職人・運送・介護・旅館・工務店と、特定の業界の話だった。今回は業界を前に出さず、**誰もが一度は感じる「自信のなさ」と「置いていかれる不安」**を主題にする。

- **見る人の幅が広い**：子育て中・子育てを終えた親、ブランクのある人、転職したい人、年齢が気になる人、ITが苦手な人。そして、その家族。
- **立場の両方に届く**：働く本人には「私でも、まだ間に合う」。経営者には「眠っている人材を、伸ばせば戦力になる」。人材不足の解決策として、いちばん多くの会社に当てはまる。
- **会社のコンセプトそのもの**：「誰もがITを活用し、自分らしく成長できる社会」を、そのまま物語にしている。
- **家族で見て、シェアしたくなる**：子どもの作文という、どの家庭にもある題材で泣ける。

## 舞台と仕掛け
- 舞台：地元の小さな会社（社員10人）。業界はあえてはっきりさせない。
- 象徴になる小道具：**娘の作文**「お母さんのしごと」。冒頭は白紙。最後は授業参観で読み上げられる。
- 象徴になる言葉：**「私なんか」**。冒頭の口ぐせ。最後は娘の作文の言葉が、その答えになる。

**感情の流れ**：自分を小さく見せる → 置いていかれる不安 → 小さな希望 → 自分の過去を認めてもらえる → 親子で学ぶ楽しさ → 頼られる喜び → 子どもに誇りに思われる。

## 一番見せたい場面
- **シーン1「お母さんの仕事なんて、書くことないよ」**：親なら誰でも胸がチクッとする一言。最初の3秒で手が止まる。
- **シーン5「10年の子育ても、“経験”だと言ってくれた」**：ブランクを“空白”ではなく“経験”と言い換える。見ている多くの人が救われる言葉で、SparkAIの姿勢がいちばん伝わる。
- **シーン6「娘と並んで、私も“宿題”」**：学び直しを、つらい努力ではなく家族の楽しい時間として見せる。
- **シーン8「娘の作文に、私の仕事が書かれていた」**：冒頭の白紙の作文と対になる。家族でシェアされやすい、泣ける着地。

## 展開のアイデア
- 主人公を入れ替えた姉妹編も作りやすい。例：父親の介護で離職していた40代男性、定年後に再就職した60代、病気から復帰した30代。どれも「ブランク」と「学び直し」でつながる。
- 15秒版の1行目だけを差し替えた冒頭のA/Bテストもしやすい。例：「10年のブランク。私だけ、置いていかれてる。」

## 注意点
- 「母親＝子育てでブランク」と決めつける印象にならないよう、姉妹編で父親や別の立場の人も描くと、より多くの人に届く。
- 授業参観の作文は、実在の子どもや学校が特定されない演出にする。
- SNSの画面やスマホには、実在のアプリやメーカーのロゴを出さない。
- 実在の会社や人物とは関係がない旨を、必要に応じて表記する。
