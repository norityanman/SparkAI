# 工務店編「剛、54歳。ガラケーを引き出しにしまった日。」

> 流れ：悩み → SNSで知る → クリック → 相談 → 学ぶ → 成功体験 → 輝かしい未来
> サービス名：SparkAI ／ 会社名：株式会社ReFast

## 舞台と仕掛け
- 舞台：地方の小さな工務店（社員8人）。主人公は**社長本人**。これまでの若手や後継ぎではなく、「いちばんITが苦手な人」が変わる話。
- 象徴になる小道具：**社長の胸ポケットのガラケー**。20年使い続けた相棒で、「これで十分」が口ぐせ。最後は自分の手で引き出しにしまう。
- 象徴になる言葉：**「俺の若い頃は」**。冒頭は若手を叱る言葉。最後は「お前たちの若い頃は、俺がもっと楽にしてやる」に変わる。
- 差別化：明るくてちょっと笑える話。頑固な社長が変わる姿は、決裁権を持つ経営者本人にいちばん刺さる。

**感情の流れ**：頑固 → 不安（また辞める）→ 小さな興味 → 笑い（3回目で押せた）→ ほっとする → 驚きと楽しさ → 若手が残る → 社長が次の世代を守る側になる。

## 一番見せたい場面
- **シーン2「また一人、辞めようとしている」**：人手不足に悩む社長なら、誰もが経験している瞬間。ここで「自分の話だ」と感じてもらう。
- **シーン4「3回目で押せた」**：笑える場面を一つ入れることで、広告っぽさが消え、最後まで見てもらいやすくなる。
- **シーン5「まず、ひとつだけ」**：ITが苦手な経営者にとって一番のハードルは「全部覚えなきゃ」という思い込み。それを外すのがSparkAIだと伝わる。
- **シーン7「颯太が、辞表を捨てた」**：数字（10分）より強い“人が残る”という成功。人材不足の解決そのもの。
- **シーン8「お前たちの若い頃は、俺がもっと楽にしてやる」**：冒頭の「俺の若い頃は」と対になる言葉。社長の変化がひと言で伝わる。

## 注意点
- 「毎晩1時間→10分」は仮の数字。実績がなければ「※イメージです」と入れる。
- 辞表をゴミ箱に捨てる描写は、退職を引き止める圧力に見えないよう、颯太が自分の意思で笑顔で捨てる演出にする。
- SNSの画面は、実在アプリのロゴを使わない架空のデザインにする。ガラケーやスマホも実在メーカーのロゴを出さない。
- 実在の会社や人物とは関係がない旨を、必要に応じて表記する。
