# 旅館編「千夏、30歳。祖母の“おもてなし帳”を開いた日。」

> 流れ：悩み → SNSで知る → クリック → 相談 → 学ぶ → 成功体験 → 輝かしい未来
> サービス名：SparkAI ／ 会社名：株式会社ReFast

## 舞台と仕掛け
- 舞台：山あいの温泉街にある、創業80年の小さな旅館。主人公は東京から戻ってきた4代目候補。
- 象徴になる小道具：**祖母の「おもてなし帳」**。常連客の好み（「枕は低め」「お茶はぬるめ」「記念日は3月」）を、祖母が何十年も手書きで書きためてきたノート。最初は祖母にしか読めない“宝の山”。最後はスタッフみんなで書き足していく帳面になる。
- 差別化：「ITで新しくする」ではなく、**受け継いできた“おもてなし”を、AIで次の世代に残す**話。古いものを捨てずに活かすので、老舗や家業を持つ経営者に刺さる。

**感情の流れ**：空回り → 無力感（いつものがわからない）→ 焦り（祖母が元気なうちに）→ 認めてもらえた喜び → 祖母との時間 → 新人が育つ → 宿の未来がつながる。

## 一番見せたい場面
- **シーン2「“いつもの”がわからない」**：家業や老舗で「あの人しか知らない」問題を抱える経営者なら、すぐに自分ごとになる。
- **シーン5「古いノートを“財産”と呼んでくれた」**：SparkAIは古いやり方を否定せず、その価値を見つけて活かす会社だと伝わる。
- **シーン6「祖母の何十年を聞いていく」**：DXの作業そのものが、祖母と孫の大切な時間になる。ほかのDX広告にはない温かさ。
- **シーン7「新人でも“いつもの”ができる」**：人に頼っていた知識がみんなのものになり、人手不足でも質が落ちないことを見せる。

## 注意点
- 「半日→30分」は仮の数字。実績がなければ「※イメージです」と入れる。
- お客の好みやアレルギーは個人情報。AIで扱う描写は、SparkAIの実際のサービス内容（個人情報の扱い、送る前に人が確認すること）と食い違わないようにする。シーン7で「千夏が確認して送る」としたのはそのため。
- SNSの画面は、実在アプリのロゴを使わない架空のデザインにする。
- 実在の旅館や人物とは関係がない旨を、必要に応じて表記する。
