# 介護編「美月、26歳。“あとでね”を言わなくなった日。」

> 流れ：悩み → SNSで知る → クリック → 相談 → 学ぶ → 成功体験 → 輝かしい未来
> サービス名：SparkAI ／ 会社名：株式会社ReFast

## 舞台と仕掛け
- 舞台：地方の小さな介護施設。主人公は若手の介護士。
- 象徴になる言葉：**「あとでね」**。記録の仕事に追われ、利用者に呼ばれても「あとでね」と言ってしまう。最後は「今いくね」に変わる。
- 象徴になる小道具：**折り鶴**。利用者のハナさんが折る。冒頭は渡せずに机の端に置かれたまま。最後は美月の手に渡る。
- 差別化：効率化の数字よりも、「人と向き合う時間が戻ってくる」ことを描く。介護の仕事に関わる人や、その家族にも響く。

**感情の流れ**：疲れ → 罪悪感（あとでね）→ 小さな希望 → わかってもらえた安心 → 前向きになる → 大切な時間が戻る → 次の世代へつながる。

## 一番見せたい場面
- **シーン2「あとでね」**：誰もが一度は言ったことのある言葉なので、介護の人に限らず胸に刺さる。この場面で見ている人の手が止まる。
- **シーン5「本当にやりたいことを言い当てられた」**：SparkAIは道具を売る会社ではなく、その人の仕事の意味を一緒に見つける会社だと伝わる。
- **シーン7「今いくね」**：冒頭の「あとでね」と対になっている。言葉が変わることで、変化がひと目でわかる。

## 注意点
- 「2時間→20分」は仮の数字。実績がなければ「※イメージです」と入れる。
- 介護記録には個人情報が含まれる。広告で「AIに記録させる」と見せるときは、SparkAIの実際のサービス内容（個人情報の扱い、最後は人が確認すること）と食い違わないようにする。シーン6のノートの「確認だけ自分で」は、そのための描写。
- SNSの画面は、実在アプリのロゴを使わない架空のデザインにする。
- 実在の施設や人物とは関係がない旨を、必要に応じて表記する。
