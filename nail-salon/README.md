# ネイルサロン 予約の仕組み

## 2つの版があります

| 版 | 場所 | 予約の保存先 | 使いみち |
|---|---|---|---|
| **Google 版** | `google/` フォルダ | Google スプレッドシート | 本番用。お客様のスマホとお店で予約を共有できます。お店の方の画面はパスワードつきです。公開のしかたは `google/公開の手順.md` を見てください。 |
| お試し版 | `index.html` | 開いたブラウザの中だけ | 画面や流れを試すためのものです。 |

できることは、どちらも同じです。以下はお試し版の説明です。

---

## お試し版

`spec.md` の説明書をもとに作った、最初の形です。

## 開き方

`index.html` をダブルクリックすると、ブラウザで開きます。インターネットにつながっていなくても動きます。

## できること

**お客様の画面**
- ネイリスト → メニュー → 日にち・時間 → お名前・お電話番号 の順に選んで予約できます。
- 出勤していない日、予約が入っている時間、メニューの時間が入りきらない時間は選べません。
- 予約番号とお電話番号で、予約の確認・キャンセル・日にちの変更ができます(予約日の前日18時まで)。
- 前日18時をすぎると、キャンセルや変更ができなくなり、お電話をお願いするご案内が出ます。
- 新しい予約も、予約日の前日18時までです。18時をすぎた日(当日をふくむ)は、カレンダーに「終」と出て選べません。

**お店の方の画面**(右上の「お店の方」を押します)
- 予約一覧:入った予約を日にちの順に見られます。
- 出勤日:ネイリストさんごとに、日にちを押して「出勤」「お休み」を切りかえます。
- メニュー:名前・かかる時間・料金を決めます。
- ネイリスト:ネイリストさんの追加や名前の変更をします。
- 動作確認:「いま」の日時を変えて、前日18時のきまりなどを試せます。見本のデータに戻すこともできます。

## 知っておいていただきたいこと

- 予約は、**開いたパソコンのブラウザの中だけ**に保存されます。ほかのパソコンやスマホとは共有されません。
- お店の方の画面には、まだパスワードがありません。
- 次の内容は仮の値です。決まったら入れかえます:メニューと料金、営業時間(10時〜19時・30分ごと)、予約を受けつける期間(30日先まで)、お客様に書いてもらうこと(お名前・お電話番号)。
- 見本のお客様やネイリストさんの名前・電話番号は、すべて作り物です。
