# Google で公開する手順

お客様のスマホから入った予約が、お店の画面にすぐ出るようにする手順です。
予約は、お持ちの Google アカウントのスプレッドシートに保存されます。だいたい15分ほどかかります。

使うファイルは、このフォルダの2つです。

- `Code.gs`:Google 側のプログラム
- `index.html`:画面

どちらも「メモ帳」などで開いて、中身をすべてコピーして使います。

---

## 1. スプレッドシートを作る

1. パソコンで [Google スプレッドシート](https://sheets.google.com) を開きます。
2. 「空白のスプレッドシート」を押します。
3. 左上の「無題のスプレッドシート」を押して、名前を「ネイルサロン予約」にします。

## 2. プログラムを入れる

1. スプレッドシートの上のメニューで、「拡張機能」→「Apps Script」を押します。新しいタブが開きます。
2. 左上の「無題のプロジェクト」を押して、名前を「ネイルサロン予約」にします。
3. 左の一覧の「コード.gs」を押します。右側にある文字をすべて消して、`Code.gs` の中身を貼りつけます。
4. 左の「ファイル」の横の「+」→「HTML」を押します。名前に `index` と入れて、Enter キーを押します(後ろの `.html` は自動でつきます)。
5. 右側にある文字をすべて消して、`index.html` の中身を貼りつけます。
6. 上の保存のマーク(フロッピーディスクの絵)を押します。

## 3. はじめの準備をする

1. スプレッドシートのタブに戻って、ブラウザの再読み込みを押します。
2. 上のメニューに「予約の設定」が出ます(出るまで数秒かかることがあります)。
3. 「予約の設定」→「はじめの準備をする」を押します。
4. はじめてのときだけ、「承認が必要です」と出ます。次の順に押してください。
   - 「OK」を押す。
   - ご自分の Google アカウントを選ぶ。
   - 「このアプリは Google で確認されていません」と出たら、左下の「詳細」→「ネイルサロン予約(安全ではないページ)に移動」を押す。ご自分で作ったプログラムなので、心配ありません。
   - 「許可」を押す。
5. もう一度「予約の設定」→「はじめの準備をする」を押します。「準備ができました」と出れば完了です。下に「予約」「ネイリスト」「出勤日」「メニュー」のシートができています。

## 4. お店の画面のパスワードを決める

1. 「予約の設定」→「お店の画面のパスワードを決める」を押します。
2. 8文字以上のパスワードを2回入れます。
3. パスワードは、紙に書くなどして、お店の方だけで大切に持っていてください。

パスワードを変えたいときも、同じメニューからいつでも決めなおせます。

## 5. 公開する

1. Apps Script のタブに戻ります。
2. 右上の「デプロイ」→「新しいデプロイ」を押します。
3. 「種類の選択」の横の歯車マークを押して、「ウェブアプリ」を選びます。
4. 次のように選びます。
   - 説明:「最初の公開」
   - 次のユーザーとして実行:**自分**
   - アクセスできるユーザー:**全員**
5. 「デプロイ」を押します。
6. 「ウェブアプリ」の下に出る URL(`https://script.google.com/macros/s/…/exec`)をコピーします。

この URL が予約のページです。お客様にはこの URL をお伝えください。お店の方も、同じ URL を開いて右上の「お店の方」を押します。

## 6. 使いはじめる前に

はじめは、見本のデータ(作り物の名前と電話番号)が入っています。

1. 予約のページを開いて、お客様の画面とお店の方の画面を試してみてください。
2. 試し終わったら、お店の方の画面で、次のことをします。
   - 「ネイリスト」:本物のネイリストさんのお名前に変える。
   - 「出勤日」:出勤する日を決める。
   - 「メニュー」:本物のメニュー・時間・料金に変える。
3. スプレッドシートの「予約」シートで、見本の予約の行(2行目から)を消します。行番号を右クリックして「行を削除」を押します。

---

## 知っておいていただきたいこと

- **スプレッドシートは、ほかの人と共有しないでください。** お客様のお名前と電話番号が入っています。
- お客様の画面からは、ほかのお客様のお名前や電話番号は見えません。お店の方の画面はパスワードがないと開けません。
- スプレッドシートの中身を直接書きかえることもできます。ただし、列の順番や、一番上の行(見出し)は変えないでください。
- ログインしたままでいられるのは6時間です。そのあとは、もう一度パスワードを聞かれます。
- パスワードを10回続けてまちがえると、10分間はログインできなくなります。

## プログラムを新しくしたとき

`Code.gs` や `index.html` を新しいものに入れかえたときは、次のようにすると、URL を変えずに新しくできます。

1. Apps Script で、2. と同じように中身を貼りかえて保存します。
2. 右上の「デプロイ」→「デプロイを管理」を押します。
3. 鉛筆のマーク(編集)を押します。
4. 「バージョン」で「新バージョン」を選んで、「デプロイ」を押します。
