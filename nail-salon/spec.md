# ネイルサロン 予約の仕組み spec

お客様が自分でネイルの予約をとれる仕組みの説明書です。
まだ作っていません。この内容でよいか確認してから作りはじめます。

---

## 1. 誰が使うか

| 使う人 | 何に使うか |
|---|---|
| **お客様** | 自分で予約をとる。予約を確認する。キャンセルや日にちの変更をする |
| **お店の人** | 入った予約を見る。ネイリストさんの出勤日やメニューを決めておく |

- ネイリストさんは2人以上います。

## 2. 必ずほしいこと

### 予約をとる
- お客様が、自分で予約をとれる。
- 予約は「担当のネイリストさんを選ぶ → メニューを選ぶ → 日にちと時間を選ぶ → 予約する」の順に進む。
- お客様が、担当のネイリストさんを選べる。
- お客様が、メニューを選べる。メニューごとに、かかる時間がちがう。

### 空いている時間だけ選べる
- ネイリストさんごとに、出勤する日を決めておける。
- お客様は、選んだネイリストさんが出勤している日だけ選べる。
- すでに予約が入っている時間は選べない。
- メニューの時間が入りきらない時間は選べない。
- 新しい予約は **予約日の前日18時まで** 受けつける。18時をすぎた日(当日をふくむ)は選べない。

### キャンセルと日にちの変更
- お客様が、自分でキャンセルや日にちの変更をできる。
- できるのは **予約日の前日18時まで**。
- 18時をすぎたら画面ではできないようにして、「申し訳ありません、前日18時をすぎたため、お電話でご連絡いただけますか」のように、やさしくご案内する。

### お店の人の画面
- お店の人が、入った予約を見られる。

### 見た目と言葉
- 色はテーマカラーの **ターコイズブルー** を中心に、落ち着いた見やすい画面にする。
- ボタンや案内の言葉は、ていねいでやわらかくする。

## 3. 今回は作らないこと

今回は話に出ていないので、作りません。ほしくなったら、あとで足します。

- 予約が入ったときや前の日に送る、メールなどのお知らせ
- お金の支払い(ネットでの前払いなど)
- お店の人が、電話で受けた予約を書きこむ機能
- ポイントカードや会員ランクなどの特典
- 売上の集計

## 4. できたと言える状態

次のことが全部できたら、「できた」とします。

- [ ] お客様が、ネイリストさん → メニュー → 日にち・時間 の順に選んで、予約をとれる。
- [ ] ネイリストさんが出勤していない日は、選べないようになっている。
- [ ] すでに予約がある時間や、メニューの時間が入りきらない時間は、選べないようになっている。
- [ ] お客様が、前日18時までなら、自分でキャンセルや日にちの変更をできる。
- [ ] 前日18時をすぎると、キャンセルや変更ができず、やさしいご案内が出る。
- [ ] 前日18時をすぎた日は、新しい予約ができないようになっている。
- [ ] お店の人が、入った予約を見られる。
- [ ] 画面がターコイズブルーを中心にした色で、言葉がやわらかくなっている。
- [ ] テスト用のデータには、本物のお客様の名前や電話番号を使っていない。

## メモ:あとで決めること

次のことは、あとでお店の方が決めます。決まったら、ここに書き足します。

- 予約のときに、お客様に書いてもらうこと(お名前、連絡先など)
- 何日先まで予約を受けるか
